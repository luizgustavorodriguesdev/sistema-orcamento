# Manual do Usuário - Como Configurar o Menu em Destaque

Este manual instrui o administrador do sistema sobre como adicionar ou remover itens no menu em destaque do storefront.

---

## Passo a Passo para Destacar Itens

### 1. Destacar Categorias
1. Vá até o Painel Administrativo do Sistema.
2. Acesse a seção de **Categorias**.
3. Clique em **Adicionar Nova Categoria** ou **Editar** uma categoria existente.
4. Marque a caixa de seleção **Exibir no Menu em Destaque**.
5. Clique em **Guardar Categoria**. A categoria selecionada começará a aparecer imediatamente na barra horizontal do storefront.

### 2. Destacar Páginas Institucionais
1. Acesse a seção de **Páginas** no painel administrativo.
2. Clique em **Criar Página** ou **Editar** uma página existente.
3. Marque a caixa **Exibir no Menu em Destaque**.
4. Clique em **Salvar Alterações**. A página começará a aparecer no menu em destaque (se estiver com status ativa).

### 3. Destacar Produtos Específicos
1. Acesse a seção de **Produtos** no painel.
2. Crie ou Edite o produto desejado.
3. Na seção "Destaque do Produto", marque a opção **Exibir no Menu em Destaque**.
4. Salve as alterações. Produtos destacados receberão um estilo diferenciado com um botão de preenchimento cheio na cor da marca para maior atração de cliques!
